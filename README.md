# Vera Note

Vera Note is a desktop note-taking and workspace tool designed specifically for developers, creators, and artists working with ComfyUI and Stable Diffusion. It allows you to easily manage your AI models, workflow information for generated images, prompt notes, daily agendas, and visual brainstorm boards—all from a single location.

## Key Features

**Model Library and Automatic Scanning:** Automatically scans, indexes, and organizes Stable Diffusion and ComfyUI model folders (Checkpoints, LoRAs, etc.) on your computer. By reading SafeTensors model headers directly, it automatically extracts embedded trigger words, base model architecture (SD 1.5, SDXL, Flux, etc.), and training details right from within the file itself. You can easily view trigger words, add custom tags, and keep usage notes all in one place.

**ComfyUI PNG Workflow and Metadata Extraction:** Automatically reads, saves, and allows you to reuse the embedded workflow information within PNG images generated by ComfyUI. You can do all of this easily using just the “drag-and-drop” method.

**Notebooks and Markdown Notes:** You can organize your prompt ideas, test results, parameter groups, or general notes hierarchically under notebooks. The integrated Markdown editor lets you format your notes however you like.

**Agenda, Daily Notes, and Routine Tracking:** Manage your workflow on a clean calendar. You can jot down quick notes for each day, track your to-do tasks, and set up recurring routines to build consistent creative habits.

**Corkboard:** A freeform visual pinboard where you can pin spontaneous ideas, workflow plans, and reminders. Use color-coded cards and pins to visualize your thoughts freely.

**Flexible and Modular Interface:** You can convert detail panels into free-standing windows or dock them back to the main window (QDockWidget architecture). Thanks to dark theme support and a customizable appearance, it easily adapts to your work environment.

**Incognito Mode:** Use the Ctrl + Shift + N shortcut to quickly enable incognito mode and use your notes and workspace with a focus on privacy during screen shares or recordings.

**Multilingual Support:** Turkish and English language options are available. You can change the language at any time from the Settings menu.

## Installation & Usage

### System Requirements
- Python 3.10 or higher
- Windows 10 / 11

### Running from Source

1. Clone the repository:
   ```bash
   git clone https://github.com/MertKB/VeraNote.git
   cd VeraNote
   ```

2. Create and activate a virtual environment (recommended):
   ```powershell
   python -m venv .venv
   # Windows PowerShell:
   .\.venv\Scripts\Activate.ps1
   # Command Prompt (CMD):
   .\.venv\Scripts\activate.bat
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Launch the application:
   ```bash
   python main.py
   ```

### Building Standalone Windows App (.exe)

To run Vera Note on systems without Python installed, build a single executable package using PyInstaller:

1. **Build (`build.ps1`):**
   ```powershell
   .\build.ps1
   ```
   The compiled executable will be placed in `dist/VeraNote/VeraNote.exe`.

2. **Shortcut Installation (`install.ps1`):**
   ```powershell
   .\install.ps1
   ```
   Adds `Vera Note` shortcuts to your Desktop and Start Menu.

## Data Privacy

- Your database and application data are stored locally in your user directory (`%USERPROFILE%\.veranote_data\veranote.db`).
- No personal data, model paths, or prompt contents are uploaded to code repositories or external servers.
