# Vera Note

    Vera Note is a desktop note-taking tool designed specifically for developers and content creators working with ComfyUI and Stable Diffusion. It allows you to easily manage your AI models, workflow information for the images you generate, and your prompt notes—all from a single location.

Key Features

    Model Library and Automatic Scanning: It automatically scans, indexes, and organizes Stable Diffusion and ComfyUI model folders (Checkpoints, LoRAs, etc.) on your computer. You can add custom tags and notes to your models.

    You can store trigger words, custom tags, and usage notes for your models all in one place.

    ComfyUI PNG Workflow and Metadata Extraction: It automatically reads, saves, and allows you to reuse the embedded workflow information within PNG images generated by ComfyUI. You can do all of this easily using just the “drag-and-drop” method.

    Notebook: It offers an integrated note area designed for you to record your prompt ideas, test results, parameter groups, or general daily notes.

    Flexible and Modular Interface: You can convert detail panels into free-standing windows or dock them back to the main window (QDockWidget architecture). Thanks to dark theme support and a customizable appearance, it easily adapts to your work environment.
    
    Incognito Mode: Use the Ctrl + Shift + N shortcut to quickly enable incognito mode and use your notes and workspace with a focus on privacy.

    Multilingual Support: Turkish and English language options are available. You can change the language at any time from the Settings menu.

Developer’s Note

    “My primary goal in developing this app was to address the shortcomings I personally experienced in AI and visual production processes. Since I couldn’t find a tool that fully met my needs, I brought this project to life as a solution that would not only fulfill my own requirements but also allow me to customize its appearance and structure exactly as I wanted.
    Even if you’re not interested in visual creation, I believe its flexible structure can easily meet your general note-taking needs as well."

## Installation & Usage

### System Requirements
- Python 3.10 or higher
- Windows 10 / 11

### Running from Source

1. Clone the repository:
   ```bash
   git clone https://github.com/MertKB/VeraNote.git
   cd VeraNote
   ```

2. Create and activate a virtual environment (recommended):
   ```bash
   python -m venv .venv
   # On Windows:
   .venv\Scripts\activate
   # On Linux/macOS:
   source .venv/bin/activate

   # Install dependencies
   pip install -r requirements.txt
   ```

3. Launch the application:
   ```bash
   python main.py
   ```

### Building Standalone Windows App (.exe)

To run Vera Note on systems without Python installed, build a single executable package using PyInstaller:

1. **Build (`build.ps1`)**:
   ```powershell
   .\build.ps1
   ```
   The compiled executable will be placed in `dist/VeraNote/VeraNote.exe`.

2. **Shortcut Installation (`install.ps1`)**:
   ```powershell
   .\install.ps1
   ```
   Adds `Vera Note` shortcuts to your Desktop and Start Menu.

## Data Privacy

- Your database and application data are stored locally in your user directory (`%USERPROFILE%\.veranote_data\veranote.db`).
- No personal data, model paths, or prompt contents are uploaded to code repositories or external servers.
